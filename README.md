# Graphite Defects and Graphene Raman Data Analysis: Defects, Doping, and Strain

Graphene Raman Analyzer is a local Windows application for analyzing Raman spectra of graphene and graphite, including highly oriented pyrolytic graphite (HOPG).

[Download the Windows x64 portable release](https://github.com/TianzeHu123/graphite-defects-and-graphene-raman-data-analysis/releases/latest)

- Fit Raman peaks in individual spectra, spatial maps, and time series.
- Inspect peak positions, heights, areas, widths, and the D/G intensity ratio.
- Compare defect-related signals across maps and acquisition times. Explore doping and strain using G and 2D peak shifts in graphene.
- Export data as CSV and editable graphs as Origin OPJU files.

## Run the application

1. Download `GrapheneRaman-1.2.4-win-x64.zip` from Releases.
2. Extract the entire archive and keep the extracted files together.
3. Open `RamanAnalyzer.exe`. The package includes its runtime. Origin is required for OPJU export.

Spectra are processed locally. Raman-derived defect, doping, and strain estimates depend on the model and calibration used.
